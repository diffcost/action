# Security policy

## Report a vulnerability

Email [support@diffcost.dev](mailto:support@diffcost.dev) with "Security" in the subject. Please don't open a public issue for a vulnerability.

Tell us what you found, how to reproduce it, and which release or commit of the Action you used. This covers the Action in this repository and the DiffCost service at diffcost.dev.

## Supported versions

Fixes are released as a new `v1.x.y` version, which the `v1` tag follows. If you pin a release or a commit, update the pin to get them: see [Update the Action](https://diffcost.dev/docs/maintenance#update-the-action).

## How DiffCost handles your data

[Security and data](https://diffcost.dev/docs/security) lists what leaves your runner, what the DiffCost service stores, and the permissions DiffCost needs.
